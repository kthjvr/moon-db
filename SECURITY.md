# Security Policy

## Supported Versions

Security updates are provided for the latest active version of moon db only.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in moon db, please report it responsibly.

### How to Report
Please send details of the issue to:
- GitHub Issues (preferred for non-sensitive reports)
- Or contact the maintainer directly via GitHub profile message/email (for sensitive vulnerabilities)

### What to Include
- Description of the vulnerability  
- Steps to reproduce the issue  
- Affected components (if known)  
- Possible impact  

---

## Response Expectations

- Initial response: within 48–72 hours  
- Status update: provided after initial triage  
- Resolution timeline: depends on severity and complexity  

If the vulnerability is accepted:
- A fix will be prioritized and released as soon as possible  
- You may be credited unless anonymity is requested  

If the vulnerability is declined:
- A clear explanation will be provided  

---

## Scope

This policy applies to:
- Authentication flows (Google Sign-In via Firebase)  
- Firestore database access rules  
- Client-side task, calendar, and productivity features  

Out of scope:
- Issues in third-party services (Firebase, Google APIs)  
- Non-security UI bugs or feature requests
